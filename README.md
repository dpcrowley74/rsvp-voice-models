# rsvp-voice-models

Model files downloaded by the RSVP reader app for its on-device natural narration voice.

- `kokoro-v1_0.safetensors` – [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) weights (Apache-2.0, by hexgrad), in the MLX layout used by [kokoro-ios](https://github.com/mlalma/kokoro-ios).
- `voices.npz` – Kokoro voice style embeddings, as packaged in [KokoroTestApp](https://github.com/mlalma/KokoroTestApp).
